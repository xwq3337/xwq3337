### 💻 Portfolio

- 🧪 [SandboxCpp](https://github.com/xwq3337/SandboxCpp)  
  基于 C++17 的多语言安全代码判题沙箱，使用 Linux cgroup v2、namespace 和 seccomp 实现多层隔离。

- ⚖️ [NexusOJ](https://github.com/xwq3337/NexusOJ)  
  全栈在线判题系统，Go + Vue 3 + Django AI 后端，支持多语言实时评测、比赛、题解、聊天与 AI 助手。

- 🦀 [Reis OS](https://github.com/xwq3337/RustOS)  
  用 Rust 编写的 x86_64 裸机内核（Phase 1），通过 PVH 协议由 QEMU 直接引导，运行在 64 位长模式。

- 🎬 [EasyDownVideo](https://github.com/xwq3337/EasyDownVideo)  
  Rust + Tauri 跨平台桌面视频下载器，支持直链多线程分块、HLS 下载、批量任务与浏览器扩展。

- 📋 [SyncClipboard](https://github.com/xwq3337/SyncClipboard)  
  可自托管的多设备文本剪贴板同步应用，Rust 服务端 + Tauri 2 + Vue 3，支持桌面与 Android。
